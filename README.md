# Diabetes Risk & Patient Health Analytics Using Python

An end-to-end healthcare analytics project using Python to explore
diabetes risk factors, perform statistical analysis, visualize patient
health data, and build a Logistic Regression model for diabetes-risk
prediction.

## Project Overview

This project analyzes patient health records to identify patterns
associated with diabetes and demonstrates a basic machine learning
workflow for diabetes-risk prediction.

The project covers:

- Data loading and exploration
- Data cleaning and missing-value treatment
- Healthcare feature engineering
- Exploratory Data Analysis (EDA)
- Data visualization
- Correlation analysis
- Independent t-test
- Chi-Square test
- Logistic Regression
- Model evaluation
- Healthcare recommendations

### False Negative in Diabetes Screening

A false negative occurs when the model predicts that a patient is
non-diabetic when the patient actually has diabetes.

In healthcare screening, false negatives are important because a
high-risk patient may be missed and may not receive timely confirmatory
testing or clinical follow-up.

## Limitations

- The dataset contains only 20 synthetic patient records.
- The dataset is intended for educational purposes.
- Model performance cannot be generalized to a real hospital population.
- A larger and more representative dataset would be required for
  clinical validation.
- The Logistic Regression model is an analytical screening model,
  not a clinical diagnostic tool.
