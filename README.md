# Diabetes Risk & Patient Health Analytics Using Python

An end-to-end healthcare analytics project using Python to explore
diabetes risk factors, perform statistical analysis, visualize patient
health data, and build a Logistic Regression model for diabetes-risk
prediction.

## Project Overview

This project analyzes patient health records to identify patterns
associated with diabetes and demonstrates a basic machine learning
workflow for diabetes-risk prediction.

The project covers:

- Data loading and exploration
- Data cleaning and missing-value treatment
- Healthcare feature engineering
- Exploratory Data Analysis (EDA)
- Data visualization
- Correlation analysis
- Independent t-test
- Chi-Square test
- Logistic Regression
- Model evaluation
- Healthcare recommendations
